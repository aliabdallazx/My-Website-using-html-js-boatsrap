# My Website using HTML, JS & Bootstrap 5

A responsive e-commerce clothing store website built with HTML, JavaScript, and Bootstrap 5.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Product collection with Isotope filtering (All / Best Sellers / Featured / New Arrival)
- Image carousel hero header
- Special products section with hover effects
- Blog section with cards
- About Us section
- Popular products (Top Rated, Best Selling, On Sale)
- Newsletter subscription
- Footer with links, contact info, and social media

## Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (jQuery, Isotope layout library)
- Bootstrap 5.0.2
- Font Awesome 5 (icons)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/aliabdallazx/My-Website-using-html-js-boatsrap.git
   ```
2. Open `index.html` in your browser (or use a local server for best results).

## Usage

- Navigate sections via the fixed top navbar
- Use the filter buttons in the Collection section to sort products by category
- Browse special products, blog posts, and popular items
- Subscribe to the newsletter (UI demo)
